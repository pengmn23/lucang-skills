# 示例

四个完整示例：三个展示提示词模板在不同场景下怎么填，一个展示拆图结果。示例内容只作演示；示例里没有图片，拿 JSON 去生图就能看到效果。

| 示例 | 类型 | 风格速配 | 版式 | 看点 |
|---|---|---|---|---|
| [single-xhs-card.json](single-xhs-card.json) | 单张小红书干货卡 | R01 白底手绘干货 | L19 环形循环 | 单张不写系列字段；主插画用 `文字显示: 不显示`；`节点关系` 画循环 |
| [ppt-viewpoint-slide.json](ppt-viewpoint-slide.json) | PPT 单观点页 | R09 商务演示 | L54 单观点页 | 16:9；父节点为容器、子节点承载层名 |
| [series/](series/00_分图规划.json) | 两张小红书系列 | R04 自然观察手帐 | L01 封面、L16 纵向步骤 | 规划→母版→逐张；两张风格字段逐字相同，只换布局与节点 |
| [deconstruct-badge-grid.json](deconstruct-badge-grid.json) | 拆图结果（七维） | — | 4×3 圆形徽章网格 | 一张原创头像索引图的完整七维拆解：12 条文字逐字转录、节点用文字 ID 引用、无标题时如何记录。原图未随包附带 |

存成模板后的样子，见 [my-templates/U000](../my-templates/U000_示例_自然观察手帐系列/模板说明.md)：由上面的 series 示例去主体得到。

系列示例的文件：

- [00_分图规划.json](series/00_分图规划.json)：需求选择、张数依据、逐张规划
- [01_风格母版.json](series/01_风格母版.json)：锁定的风格字段，【每张填写】处留给各张
- [001.json](series/001.json)：封面，低密度例外
- [002.json](series/002.json)：步骤页，中密度

对照看 001 和 002：`视觉风格系统`、`内容标签系统`、`配色方案`、`光影效果`、`渲染参数与负向` 完全相同；变的只有核心主题、系列编号、页码、布局、标题文字和节点。
