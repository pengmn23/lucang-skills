# 字段说明

[`prompt-template.json`](prompt-template.json) 是一张图的完整提示词骨架。每个值里写着填法：`【必填】`、`【可选】`、参考字数和写什么。交付时把这些说明全部替换成实际内容；可选字段不用时**删除整个键**，不要留空说明。

## 1. 先记住三条

1. **只有三处文字会画进图里**：`标题文字内容`、各节点显示的 `标题` 和 `描述`，以及 `页码标注`（如有）。其余字段都是写给模型的绘制要求，不上屏。
2. **一张图一份完整 JSON**。做系列时每张都写全，不写「风格同上」。
3. **长度跟着字段走**：总定调一句话，风格字段写到能画出来为止，不堆形容词。参考长度见下表（中文字符数）。

## 3. 节点怎么写

一张图拆成几个有意义的节点：主插画、副标题、几张知识卡、底部金句……每个节点包含：

| 字段 | 作用 | 写法 |
|---|---|---|
| `节点ID` | 编号，不上屏 | `01`、`02`；子节点写 `02.01`。全图唯一 |
| `节点角色` | 这个节点干什么，不上屏 | 主插画、副标题、知识卡、步骤、表格、对照栏、图例、金句、引导语、页码…… |
| `视觉锚点描述` | **画什么** | 可见的主体、形态、动作、数量、大致位置。纯文字节点写「浅色纸签内的文字卡」 |
| `节点布局结构` | 节点内部怎么排 | 「六行三列，左栏序列、中栏层次、右栏状态」；无要求填 `""` |
| `文字显示` | 可选开关 | `不显示` 时标题、描述都必须是 `""`；普通节点不写或写 `显示` |
| `文字标签内容.标题` | **上屏**小标题 | 2—16 字；不需要就填 `""` |
| `文字标签内容.描述` | **上屏**正文 | 长度由密度决定；多行用 `\n` |
| `文字颜色标注` | 强调 | `强调词` 必须是本节点标题或描述里已有的词；无强调用 `[]` |
| `排版微调` | 字号和图文对应 | `字体大小` 写 Level；`位置/引线` 写紧贴、短引线或编号对应 |
| `子节点` | 嵌套 | 同结构的节点数组；没有就写 `[]`。父节点负责容器或分组，不和子节点重复画 |

**常见错误**：把「主插画」「副标题」「本页金句」写进 `标题`。这样模型会把这几个字也画出来。它们是**角色**，写进 `节点角色`；真正要显示的字才写进 `标题` 或 `描述`。

视觉锚点要写到能画出来。「表现效率的重要性」只说了意图；「左侧一叠散乱纸张，右侧三个贴好标签的文件夹，一只手正把纸放进去」才是画面。更多写法见 [09 视觉锚点与节点](../library/09_视觉锚点与节点.md)。

## 4. 信息密度怎么算

密度指**上屏字数**，不是提示词长度。统计主标题、节点标题与描述、页码以外的所有显示文字，中英文、数字、标点都按 1 字计。

| 档位 | 每张上屏字数 | 适合 |
|---|---|---|
| 纯画面 | 0 | 绘本内页、无字漫画、插画、素材页 |
| 低 | 约 50 | 封面、海报、金句卡、单幅漫画、PPT 观点页 |
| 中 | 约 150 | 手机知识卡、流程、对比、分类、教程 |
| 高 | 约 300 | 速查表、资料页、系统拆解、练习纸、PPT 数据页 |

封面和过渡页可以比所选档位少字。字数装不下时，先减装饰、调分区或拆成两张，不要只把字缩小。

## 5. 单张和系列的区别

| | 单张 | 系列 |
|---|---|---|
| 系列编号、系列风格锚点、建议参考图流程 | 删除 | 每张都写 |
| 页码标注 | 需要才写 | 通常写，会上屏 |
| 风格字段（视觉风格、标题与正文样式、配色、光影、角色设定、渲染） | 本张自定 | 先写一份**风格母版**，每张逐字复制，不改写同义词 |
| 每张可变 | 全部 | 核心主题、布局架构、视觉逻辑、标题文字、节点、节点关系、本张专属约束 |

系列里确需某张微调风格（比如数据页换成更简洁的背景），只改一两个字段，并在规划里写明哪张、改了什么、为什么。

`系列风格锚点` 推荐写法：
> 以第1张的纸纹、线条、配色、标题与正文样式、装饰系统为母版；第2—N张都把已确认的第1张作为风格参考图，不复制其布局与插图。

## 6. 少用但有用的扩展

只在内容确实需要时加，加了就在全套保持同样结构。

- **图例**：做成一个节点，`节点角色` 写「图例」，描述逐条列出符号或颜色的含义。
- **比例数据**：比例图、堆叠图需要准确比例时，加顶层 `比例数据` 对象，写口径、总量、单位、各段节点ID与数值，并确保合计正确。生图模型画不准精确比例，正式统计图建议用图表工具。
- **页码之外的固定文字**（来源、署名）：作为节点列出，不要偷偷写在约束里。

## 7. 交付前自查

- [ ] 所有【必填】说明都已替换；不用的可选键已删除，没有残留填写说明
- [ ] JSON 合法：双引号、无尾逗号、换行用 `\n`
- [ ] `节点角色` 没有被写进 `标题`；每个强调词都能在本节点文字里找到
- [ ] 上屏文字字数接近所选密度，封面等例外已说明
- [ ] 正向和负向不打架（例如要水彩质感，负向里就不能有 watercolor）
- [ ] 系列：每张风格字段与母版逐字一致，节点结构同构，编号连续
