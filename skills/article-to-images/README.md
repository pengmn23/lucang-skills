# 文章转图片提示词 · 使用说明

把一篇文章、一份提纲，甚至一句想法，变成可以直接拿去生图的提示词。可以做**一张**，也可以做**一整套**风格统一的图。

还能做两件事：**拆解一张图**（分析版式和画法，逐字识别图里的文字，反推提示词），以及把做过或拆过的图**存成模板**，下次点名直接用。

适合：小红书图文、知识图解、信息图、漫画、绘本、海报、PPT 配图、图鉴、练习纸、手帐页……

## 你需要什么

- 一个能读文件的 AI 助手（支持 skill 的 Agent 工具最好，普通对话也行）。
- 一段内容。
- 想直接出图的话，需要你用的工具能生图；做系列时，最好支持上传参考图。

**不需要**：Python、命令行、任何图片素材。整个包只有文字文件（你以后存进 `my-templates/` 的参考图除外）。

## 怎么装

1. 用 skills 命令行：`npx skills add pengmn23/lucang-skills`，选 article-to-images。或者从 [GitHub](https://github.com/pengmn23/lucang-skills) 下载，拿到 `skills/article-to-images` 文件夹，保留里面的子文件夹。
2. 支持导入 skill 的工具：把这个文件夹放进它的 skill 目录（Claude Code 是 `~/.claude/skills/`，Codex 是 `~/.codex/skills/`），或按工具说明导入。
3. 不支持的工具：把整个文件夹（或压缩包）上传给 AI，说一句「先读 article-to-images/SKILL.md，再按它处理我的内容」。
4. 只能粘贴文字时：至少给它 `SKILL.md`、`templates/prompt-template.json`、`templates/field-guide.md`，以及 `library/00_图文类型.md` 和 `library/README.md`。

## 第一次怎么说

做一张：

> 用 article-to-images，把下面这段做成一张小红书干货卡。正文：……

做一套：

> 用 article-to-images，把这篇文章做成 6 张小红书图，3:4。先问我风格和密度，选好再写提示词。正文：……

做 PPT：

> 用 article-to-images，把这份提纲做成 8 页 PPT 配图，16:9，商务风。提纲：……

有参考图：

> 参考附件图片的画法，把这篇文章做成 4 张图。不要沿用图片里的旧标题和旧内容。正文：……

想省事：

> 风格和密度你来定，直接写。

拆一张图：

> 用 article-to-images 拆解这张图，文字逐字识别出来。

用存过的模板：

> 我有哪些模板？

> 用模板 U001，把下面这篇做成 5 张图。正文：……

## 它会问你什么

- **一张图**：问 2 题，即选哪种风格（三选一）、每张放多少字（约 50、150 或 300 字，绘本漫画还可以选纯画面）。
- **一套图**：再加 2 道跟你内容有关的题，比如重点讲步骤还是讲原理。

已经说清楚的不会再问。

## 你会拿到什么

- **一张图**：一份完整的 JSON 提示词，外加几句说明。
- **一套图**：分图规划（每张讲什么）、风格母版、每张一份完整 JSON、内容取舍说明。

JSON 是带字段名的结构化文字。把一整份 JSON 粘贴到生图工具里当提示词用就行；图片比例和尺寸在生图工具里另外设置。

做一套图时，先生成第 1 张；满意后，生成后面每张都**附上第 1 张作为参考图**，整套风格才稳定。

## 拆图

给它一张图，它会按七个方面拆解：布局、主题、画法、材质质感、版式细节、全部文字、尺寸比例，最后给出一个 JSON。

- 图里所有文字**逐字**记下来，看不清的地方会标出来，不会瞎猜。
- 拆完会问你：要不要转成能直接生图的提示词？要不要存成模板？

## 模板

- **存模板**：做完一套图或拆完一张图，它会问你要不要存成模板。存下来的是**去掉原内容、只留风格和版式**的提示词，放在 `my-templates/` 里，编号 U001、U002……
- **存参考图**：存模板时会问你要不要把首图或原图一起存进去。存了，下次出图可以直接附上它当风格参考。
- **用模板**：说「用模板 U001」就会沿用那套风格，只再问你密度和内容。不点名不会自动用。
- 自带一个示例模板 U000，可以先看看存下来是什么样子。

> **分享这个 skill 前**：清空 `my-templates/`（保留里面的 README），或只留你自己原创的模板。参考图和拆图记录可能含别人作品的内容。

## 想自己动手改

- `templates/prompt-template.json`：空白模板，每个格子写着填什么、写多长。
- `templates/field-guide.md`：字段说明，哪些必填、哪些可选、哪些会画进图里。
- `library/`：按字段整理的现成写法，可以直接复制。先看 `library/00_图文类型.md` 找到你要做的图，再看 `library/README.md` 里的 12 套风格速配。
- `examples/`：一张小红书卡、一页 PPT、一套两张系列的完整示例，以及一份拆图结果示例。

只改某一张时可以说：「第 3 张改成左右对比，其他不动。」

## 需要知道的

- 生图模型不一定一字不差地画出中文，尤其是小字和长句。成图后请逐字检查专名、数字和标点。
- 提示词里写「高清」不等于输出高分辨率，尺寸请在生图工具里设。
- 数据类图片里的比例和数值，模型可能画不准；正式使用的统计图建议用图表工具。
- 提示词只使用你给的内容，不会自己编数据和案例；你的原文要准确。
