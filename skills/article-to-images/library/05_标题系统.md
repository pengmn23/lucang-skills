# 05 标题系统

用于 `标题艺术系统` 的 `艺术样式`（40—65 字）、`标题字体`（20—40 字）、`标题装饰`（25—45 字）、`标题字号`（30—55 字）。

**原则**：标题可以有艺术感，但每个字都要能认出来。写「易读」「笔画完整」比写「华丽」更重要。生图模型对中文复杂字体容易出错，越花哨越要强调可读。

## 艺术样式

| 编号 | 名称 | 可直接填入的写法 | 搭配 |
|---|---|---|---|
| T01 | 双色毛笔大字 | 朱红毛笔感大标题与深青副字形成对比，笔锋略有手工墨迹，标题下方一笔朱红短划 | A03、A10 |
| T02 | 粗黑马克笔 | 粗黑马克笔手写大字，圆润但有粗细与收笔变化，关键词下压一条荧光黄横划 | A01、A02 |
| T03 | 圆润手写两级 | 深色圆润手写主标题，副标题小一档换一种颜色，两级层次清楚 | A05、A06 |
| T04 | 粗宋印刷 | 深墨色粗宋体大字，笔画完整端正，细线装饰与浅色横幅衬底 | 图鉴、知识卡 |
| T05 | 现代粗黑 | 现代无衬线粗黑体，核心短语加粗加大，居中分两行，干净无装饰 | A34、A35、PPT |
| T06 | 衬线编辑 | 黑色大衬线标题，副题为小号无衬线，字距舒展，杂志感 | A13、A33 |
| T07 | 超大错落手写 | 超大粗黑手写字，三段错落排列、末段错开，不做规整网格标题 | A30、L46 |
| T08 | 彩虹手抄 | 两层粗手写，第一层深蓝，第二层用彩虹分色，标题下一条短彩色横幅 | A02、L14 |
| T09 | 三层装饰字 | 三层装饰衬线大字分别用三种主色，下方一条手写副句横幅 | 封面、海报 |
| T10 | 复古浮雕圆胖字 | 圆胖展示字分层上色，统一深褐色厚侧边，复古印刷浮雕感 | 复古海报 |
| T11 | 空心描边字 | 白色空心粗字配细黑轮廓，副句小号白色实心无衬线 | A27、深色底 |

| T13 | 书法冠字群 | 大号自然书法字群居于顶部留白中，笔画错落但字形可辨，旁配朱红小印 | A10 |
| T14 | 金箔毛笔 | 金箔质感毛笔飞白大字，窄高光，副句为奶油色宋体 | 庆典、节日 |
| T15 | 压缩窄黑体 | 极大的压缩窄黑体活动名，其余信息用疏排小号无衬线 | 活动海报 |
| T16 | 细长自然手写 | 细长黑色手写字，像自然写在空白纸上，不做粗字块 | A09、A23 |
| T17 | 贴纸大字 | 红白贴纸感粗大字，宽白描边与极浅灰影，像贴在纸上 | 漫画卡、金句卡 |
| T18 | 窄高手写题签 | 窄高的手写小题签放在竖向纸签或木牌上，不扩成横向大标题 | A12、A15 |
| T19 | 图鉴墨绿粗体 | 深墨绿色图鉴粗体中文标题，不做浮雕，下方一条细橄榄色下划线 | A04、A39 |
| T20 | 数字展示 | 标题中的数字超大并换成强调色，其余文字中等大小 | 数据页、清单 |

| T22 | 拼贴字母 | 每个字剪自不同纸片，颜色材质各异，整体对齐成一行 | A16、A17 |

## 标题字体

| 写法 | 适合 |
|---|---|
| 简体中文易读的粗宋体 | 图鉴、古风、文化 |
| 简体中文古风手书与粗宋混合观感；不使用不可识别的装饰字体 | 奇幻、国风 |
| 简体工整手写体，结构完整 | 手帐、笔记 |
| 简体圆润手写体 | 童趣、可爱 |
| 简体粗黑马克笔手写体 | 小红书干货 |
| 现代中文粗黑体 | PPT、商业 |
| 简体自然书法，笔画可辨 | 国风、节日 |
| 高对比衬线标题，正文为无衬线 | 编辑、杂志 |
| 超粗几何无衬线 | 海报、大字 |
| 简体细长手写 | 治愈、留白 |
| 简体正楷，配清楚的带调拼音 | 识字、语文学习 |
| 英文艺术衬线，中文副题用宋体 | 中英双语 |

## 标题装饰

| 写法 | 适合 |
|---|---|
| 标题下方一条带卷边的暗金副标题飘带，周围小星点；无发光字、投影或渐变字 | 奇幻、古籍 |
| 浅色平面横幅衬底，不加立体阴影 | 通用 |
| 一笔短朱红弧线与一枚小圆点，纯白底直接书写，不加纸签 | 极简手绘 |
| 关键词下一条半透明荧光横划，其余不加装饰 | 干货卡 |
| 标题右侧一枚朱红方印 | 国风 |
| 标题放在撕边纸条上，纸条有轻微投影 | 拼贴 |
| 标题外一个手绘圆角框，框线略有抖动 | 手绘笔记 |
| 标题左侧一个彩色小图标，标题与图标基线对齐 | 清单、PPT |
| 标题上方一行小号英文或小标签，字距加宽 | 编辑、杂志 |
| 标题下方细双线分隔，与正文区明确分开 | 资料页 |
| 木牌或金边牌匾承载标题 | 童话、活动 |
| 无装饰，只靠字号与留白 | 极简、PPT |

## 标题字号

| 写法 | 适合 |
|---|---|
| 大标题 Level 1（缩略图也醒目）；副标题 Level 2；分区题 Level 2；正文 Level 3 | 通用 |
| Level 1，标题区占约12%—18%画高；资料页优先保留说明空间，不用大标题挤压内容 | 高密度页 |
| Level 1，标题与主视觉共同占画面约60%，正文极少 | 封面、海报 |
| Level 1 位于上方窄竖签，不扩成横向大标题 | 竖签版式 |
| Level 1，远看可读；正文不小于标题的三分之一 | PPT |
