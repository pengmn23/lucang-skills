# 09 视觉锚点与节点

用于节点的 `节点角色`、`视觉锚点描述`，以及可选的 `节点关系`、`角色设定`。

## 一、节点角色（不上屏）

`节点角色` 告诉模型这个节点在画面里干什么。**它不是要画出来的字。**

| 角色 | 用途 | 文字怎么填 |
|---|---|---|
| 主插画 | 全图视觉中心 | 通常 `文字显示: 不显示`，标题、描述都为空 |
| 副标题 | 主标题下的一句话 | 标题空，描述写副标题句 |
| 知识卡 / 要点 | 一条知识 | 标题写要点名，描述写解释 |
| 步骤 | 流程中的一步 | 标题写「01 准备」，描述写动作 |
| 表格 | 多行多列信息 | 标题写表名，描述每行一句，用 `\n` 分隔，列用「｜」 |
| 对照栏 | 左右/前后对比中的一侧 | 标题写这一侧的名字 |
| 图鉴条目 | 网格中的一个对象 | 标题写名称，描述可空 |
| 展签 / 注释 | 指向主图某部位的说明 | 标题写部位名，描述写作用 |
| 图例 | 颜色、符号的含义 | 描述逐条列出 |
| 漫画格 / 旁白 | 叙事中的一格 | 描述写旁白或对话 |
| 金句 / 结论 | 底部收束句 | 标题空，描述写那句话 |
| 引导语 | 关注、下一页、商品卡等 | 描述写引导文字，只在需要的那张出现 |
| 装饰 | 纯装饰的独立元素 | `文字显示: 不显示` |

## 二、视觉锚点怎么写（20—120 字）

公式：**画什么主体 ＋ 形态/动作/数量 ＋ 大致位置 ＋（必要时）不要什么**。

| 差 | 好 |
|---|---|
| 表现整理资料的重要性 | 左侧一叠散乱的纸张，右侧三个贴好标签的文件夹，一只手正把纸张按类放入 |
| 一个知识卡 | 浅色撕边纸签内的文字卡，左上角一个小书本图标 |
| 主插画，体现世界观 | 中轴为漂浮山体上九个层级城邦，最上层钟楼城堡，云海与铁路桥串联各层；前景一个原创旅行者背影 |
| 一张表格 | 六行三列的古纸表格，左栏放等级，中栏放名称，右栏放说明，行线笔直 |

要点：
- **数量写准**：「五个台阶」「三只碗」。图鉴、网格、步骤的数量必须与节点一致。
- **位置写大概**：左侧、中央偏下、右上角即可，精确的图文对应写在 `位置/引线`。
- **纯文字节点也要写容器**：「留白区域内的文字卡」「金色卷轴横幅，暗墨大字居中」。
- **原创形象**：IP 内容写「原创角色」「不参照影视动漫形象」。
- **锚点不上屏**：这里的字是给模型看的绘制要求，不会画进图里。

## 三、把抽象内容变成能画的东西

知识类内容常常没有天然的画面。下面是常用的视觉转化。选用时要**符合原文意思**，不要为了好看引入原文没有的关系。

| 抽象内容 | 可画的视觉锚点 |
|---|---|
| 成长、进阶、等级 | 一级比一级高的台阶；从种子到大树的四个阶段；螺旋上升的阶梯 |
| 积累、复利 | 一个透明罐子被逐渐装满；越滚越大的雪球；层层叠高的积木 |
| 选择、分歧 | 一条路在面前分成两条，路口有路牌；两扇不同颜色的门 |
| 流程、顺序 | 一条连续的小路串起几个站点；传送带上依次经过的物件 |
| 循环、习惯 | 环形跑道；首尾相接的齿轮；绕一圈回到起点的小火车 |
| 系统、协作 | 互相咬合的齿轮组；几条颜色不同的线路汇入同一个车站 |
| 结构、组成 | 被切开的剖面，每层一个小场景；沿轴线拆开的爆炸图 |
| 分类、归纳 | 一个多层抽屉柜，每层一类；分层陈列瓶；贴着标签的收纳盒 |
| 对比、差异 | 同一个角色在左右两个场景做不同的事；天平两端 |
| 平衡、取舍 | 天平；一座摇摇晃晃但没倒的物件塔 |
| 进度、完成度 | 液体注入一条进度条；地图上一条路走到一半 |
| 专注、聚焦 | 舞台聚光灯照亮一个小人；放大镜下的一个局部 |
| 信息过载 | 漫天飞舞的纸片包围一个小人；碎词纸条环绕一个小主体 |
| 负担、压力 | 一个小角色背着几块写有名字的石头；肩上越来越高的箱子 |
| 转变、开启 | 一件日常物件变成一扇透出暖光的门；破开纸面露出另一个世界 |
| 连接、关系 | 插头与插座；彩色线缆在几个底座之间弯曲穿过 |
| 记忆、收藏 | 装着小照片的玻璃罐；打开的旧皮箱里是纸雕小世界 |
| 时间、阶段 | 从左到右的季节变化；一根纵轴上依次排列的实物 |
| 起点与目标 | 路线起点的小车站与远处山顶的旗子 |
| 内在世界 | 一个大轮廓剪影里装着一个完整的小场景 |
| 规模、尺度 | 巨大物件旁边的极小人物；同一基线上高矮不同的对象 |
| 风险、边界 | 悬崖边的护栏；地图上用虚线圈出的区域 |
| 陪伴、支持 | 两个角色并肩坐着的背影；一只手扶住另一只手 |
| 观点、态度 | 一个角色举着写有关键词的牌子；一句大字压在单一场景上 |

## 四、按图文类型的锚点模板

| 类型 | 锚点模板 |
|---|---|
| 封面主插画 | [主体]位于画面中央偏下，[动作/姿态]，周围[环境]，前景[小元素]；留出顶部标题区 |
| 知识卡 | [颜色]圆角卡片内的文字卡，左上角一个[小图标]，卡片下方[小插图] |
| 图鉴条目 | 一个完整的[对象]，[视角]，[关键特征]，不裁切；名称在正下方 |
| 步骤 | [手/角色]正在[动作]，手边[工具]，结果[状态]；只新增这一步的变化 |
| 对照栏 | 同一个[角色]在[场景]中[做法 A]，表情[情绪]；与另一栏构图对称 |
| 展签 | 浅色小纸签，细引线精确指向主图的[部位] |
| 漫画格 | [角色]在[地点]，[动作]，[表情]；镜头[远/中/近景] |
| 数据图 | [图表类型]，[N]个[柱/扇区/层]，按节点数值比例绘制，旁边数值逐字标注 |
| 地图 | 非比例的主题地图，[N]个区域各有一个地标：[地标列表] |
| 练习区 | [题型]作答区：[N]个空白[框/横线/待涂区域]，全部未填写 |
| PPT 图示 | 一个简洁的[图形]（如三个同心圆、上升箭头），扁平矢量，占页面中部 |

## 五、节点关系（可选）

只有流程图、关系图、因果图需要。每条关系都要有原文依据；没有明确关系，就不要画箭头。

```json
"节点关系": [
  { "起点ID": "01", "终点ID": "02", "关系类型": "下一步", "线型": "细黑实线＋小箭头，起止清楚，不穿过文字" }
]
```

常用关系类型：下一步、导致、包含、属于、对比、转化为、回到、汇入。线型常用：细实线＋箭头（顺序）、虚线（参考/可选）、粗色线（主线）、双向箭头（互相影响）。

关系文字如果要显示（如箭头上写「导致」），把它作为一个节点列出，`节点角色` 写「关系标签」，并且同一个关系词只出现一次。

## 六、角色设定（可选）

漫画、绘本、系列固定角色时使用，写在顶层 `角色设定`。写**能被画出来、每格都能检查的特征**。

```json
"角色设定": {
  "主角": "原创短发女孩，约二十岁，齐肩黑发，左侧一枚黄色发夹，米白毛衣配深蓝背带裤，圆脸大眼",
  "配角": "原创橘色短毛猫，尾巴尖为白色，脖子上一条红色细项圈",
  "跨图锁定": "发夹始终在左侧；毛衣与背带裤颜色不变；猫的白尾尖每格可见"
}
```

- 写年龄感时要具体（「约二十岁」），Q 版比例不等于儿童。
- 两个以上角色时写清谁在左、谁在右，以及互动动作（递物、并肩、对视）。

## 七、无字节点

纯画面的节点加 `"文字显示": "不显示"`，标题、描述都填 `""`，强调词 `[]`。这样模型不会自己编一个标签。整张无字时，主标题也设为不显示，并在约束里写「画面不出现任何文字、字母或数字」。
