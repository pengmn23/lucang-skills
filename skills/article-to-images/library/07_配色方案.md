# 07 配色方案

用于 `配色方案` 的五个颜色和 `使用规则`。每个颜色写 `#色号 中文色名`，例如 `#B3261E 朱红`。

**原则**：
- 一套图只用一组色板。主色撑结构，辅助色铺次级区域，强调色只给少数关键词。
- 文字区保持**浅底深字**（或深底浅字），对比要足。
- `使用规则` 写清每种颜色负责什么，40—65 字。

## 使用规则（40—65 字）

| 写法 | 适合 |
|---|---|
| 浅底深字；[主色]组织结构，[辅助色]承托标题，[强调色]少量强调；全套保持相同含义 | 通用 |
| [主色]用于标题与提示，[辅助色]用于次级标题与建筑云海，[强调色]用于卷轴边框星光；正文全部放浅色背景 | 插画＋文字 |
| 全页只用这一组颜色；背景与文字保持对比，层级不靠杂色堆叠 | 极简 |
| 只用一种墨色，靠线宽与疏密区分层次，不加第二种颜色 | 单色 |
| 色板固定；每个主体的颜色按节点描述，但不超出这一组 | 图鉴、角色 |
| 每个分类固定一种颜色，图例、标签与图形同色对应，全套不换 | 分类、线路图 |
| 数据系列依次用[主色][辅助色][强调色]，背景与网格只用灰 | 数据图 |
| 深色背景浅色字；图表用高亮色，正文不用彩色 | 深色 PPT |
| 纯黑白，不加灰度填充，留白供涂色 | 练习纸 |
| 允许少量[点缀色]出现在插画中，但不进入文字区 | 插画为主 |
