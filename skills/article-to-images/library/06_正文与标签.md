# 06 正文与标签

用于 `内容标签系统` 的各字段。正文要比标题**更规整、更好读**，不跟着标题一起变形。

## 正文艺术样式（30—50 字）

| 编号 | 名称 | 可直接填入的写法 | 适合 |
|---|---|---|---|
| C01 | 古籍印刷 | 古籍印刷感的清楚简体中文，汉字笔画完整，表格行列线条笔直 | 奇幻、古风资料页 |
| C02 | 平面印刷 | 清楚的平面印刷文字，不扭曲、不加立体描边，左对齐 | 通用 |
| C03 | 工整手写 | 深灰工整手写，节点标题稍粗，说明为短句，行距宽松 | 手帐、笔记 |
| C04 | 马克笔手写 | 黑色马克笔手写正文，字形圆润端正，关键词荧光横划 | 干货卡 |
| C05 | 卡片标题＋说明 | 卡片标题粗、说明细，同一层级字号一致，编号颜色可变但结构不变 | 九宫格、清单 |
| C06 | 图鉴名称 | 每个条目下方一行名称，名称黑色细笔，说明小号但可读 | 图鉴 |
| C07 | 旁注竖排 | 旁侧短句细笔竖排，底部说明简洁横排，不贴在主体表面 | 海报、古风 |
| C08 | 对话轮次 | 每轮对话一行，说话人头像在侧，文本统一对齐，中文在上、英文在下 | 语言学习、漫画 |
| C09 | 漫画旁白 | 旁白用圆角框内短句，对话用带尾巴的气泡，字数少、字号大 | 漫画 |
| C10 | 演示要点 | 每条要点一行，不超过两行，前有小圆点或编号，行距 1.5 倍 | PPT |
| C11 | 题目与指令 | 题号粗、指令短，作答横线与选择框清楚，空白处不填写 | 练习纸 |
| C12 | 数据标注 | 数字比说明大一档，单位紧跟数字，数值与图形一一对应 | 数据图 |
| C13 | 纯画面 | 不显示正文，形象与姿态承担识别 | 绘本插画、无字漫画 |

## 正文字体（15—30 字）与通用字体（15—35 字）

| 正文字体 | 通用字体（数字、英文、编号） |
|---|---|
| 简体中文易读宋体或黑体 | 等宽阿拉伯数字，与正文同色 |
| 简体工整手写体 | 圆润手写数字与编号 |
| 现代中文黑体，常规字重 | 无衬线英文与数字 |
| 简体清楚细宋体 | 细衬线数字，适合年份 |
| 简体圆润手写 | 彩色圆形编号内白色数字 |
| 简体正楷 | 带声调的清楚拼音 |

## 基础字号（30—55 字）

| 写法 | 适合 |
|---|---|
| 节点标题 Level 2；说明 Level 3；手机放大后可读 | 通用 |
| 名称 Level 2，说明 Level 3；高密度时优先减少装饰而不是缩成脚注 | 资料页 |
| 所有名称同字号、同基线间距 | 图鉴 |
| 旁白 Level 2，手机可读；不使用细小解释字 | 漫画、绘本 |
| 正文 Level 3，远看可读；每页文字不超过六行 | PPT |
| 题干 Level 2，提示 Level 3；作答区足够书写 | 练习纸 |

## 通用颜色

正文主色写一个色号，通常与配色方案的「正文颜色」相同，如 `#2B2B2B`。深色底用浅色字，如 `#F4EFE6`。

## 标签背景框（25—45 字）

| 编号 | 写法 | 适合 |
|---|---|---|
| K01 | 暖白／淡黄旧纸框、细墨描边、彩色标题条；表格用不透明浅底并保留充分行距 | 奇幻、古籍 |
| K02 | 暖白色薄边小标签，留足内边距 | 通用 |
| K03 | 无框直接排在留白处，与主体保持一字距离 | 极简、海报 |
| K04 | 浅彩虚线圆角卡，不加重投影 | 手帐、九宫格 |
| K05 | 白色大圆角面板配彩色栏目胶囊 | 照片知识卡 |
| K06 | 完整圆形浅彩底＋白色厚边，每圆独立 | 圆贴纸 |
| K07 | 撕边纸签，轻微卷边与柔影 | 拼贴、手作 |
| K08 | 细黑矩形框，框与框错层 | 编辑、拼贴封面 |
| K09 | 仅关键词后方用半透明马克笔色带，不套卡片 | 手写笔记 |
| K10 | 木牌、竖签或卷轴作为文字容器 | 童话、古风 |
| K11 | 圆角对话框与旁白框，旁白框无尾巴 | 漫画 |
| K12 | 细白引线指向零件，标签无框 | 爆炸图、剖面 |
| K13 | 虚线圆角区与连续的空白填写线，不预填答案 | 练习纸、记录表 |
| K14 | 浅灰圆角色块承载要点，色块之间等距 | PPT |
| K15 | 黑板上直接书写，无框 | 粉笔 |
| K16 | 一体化的表格：表头深色底浅色字，表身浅色底深色字 | 资料页、矩阵 |

## 局部强调逻辑（30—50 字）

| 写法 |
|---|
| 只对节点里明确列出的强调词使用强调色，不自行添加词或改色 |
| 标题中的重点词用强调色；正文只把每组最关键的一个名称用强调色，不给所有行乱加颜色 |
| 关键词下方荧光横划，横划颜色统一；其他词不加 |
| 强调靠加粗和字号，不靠颜色；全图只用一种文字颜色 |
| 数字用强调色并加大一号，单位保持正文色 |
| 无文字强调；靠角色造型和服饰区分，不把装饰色解释成等级 |

> 强调词必须是该节点 `标题` 或 `描述` 里**已经存在**的词；不要为了强调额外加字。
