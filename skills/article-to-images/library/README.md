# 提示词库

这里是按字段整理的现成写法，可以直接填进 [`prompt-template.json`](../templates/prompt-template.json) 的对应字段。写法是从约 200 套图文模板中提炼的通用设计语言，已去掉原主题、专名和品牌。

## 怎么用

1. **先定类型**：读 [00 图文类型](00_图文类型.md)，找到这次要做的图，记下推荐的比例、密度、版式和画法。
2. **再定风格**：在 [01 视觉美学](01_视觉美学与氛围.md) 定总调，再去 02 媒介、03 背景、05 标题、06 正文、07 配色、08 光影各挑一条。下面的「风格速配」已经搭好了 12 套，可以直接用。
3. **然后排版**：在 [04 版式布局](04_版式布局.md) 选版式，把方括号换成本次内容。
4. **写节点**：按 [09 视觉锚点与节点](09_视觉锚点与节点.md) 把内容拆成节点，抽象内容用第三节转成画面。
5. **加约束**：从 [10 约束与负向](10_约束与负向.md) 选通用条目，补本类型条目，检查正负向不冲突。

库里的写法是**起点，不是终点**：可以改词、合并、换颜色，以贴合本次内容为准。不要把不同风格的写法混在同一张图里，除非是有意设计。
