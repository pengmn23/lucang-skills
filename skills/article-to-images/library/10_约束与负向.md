# 10 约束与负向

用于 `硬性指令约束` 的 `必须达成`（5—9 条）和 `回避`（8—15 个短词），以及 `渲染参数与负向/负向提示词`（15—25 个英文词）。

**先选通用条目，再按图文类型补专属条目。** 方括号内按本张替换。

## 必须达成

### 通用（几乎每张都用）

1. 画布严格为 [3:4]；所有文字为正确的简体中文，清晰可读，无错别字和乱码。
2. 主标题严格使用「标题文字内容」，不擅自添加前缀、删字或改标点。
3. 图中只出现「标题文字内容」、各节点显示的标题和描述，以及「页码标注」（如有）；字段名、色号、节点角色和指令不上屏。
4. 强调词只使用「文字颜色标注」规定的颜色，未列出的词不额外改色。
5. 文字通过紧贴或短引线对应视觉锚点，关系清楚、不交叉、不遮挡主体。
6. 事实、数字、名称以节点文字为准，不自行添加例子、数据和设定。
7. 不出现水印、签名、品牌标识、平台 Logo 或界面截图。

### 系列

- 统一使用风格母版的背景、画法、配色、标题与正文样式；每张更换新画面，不跨页照搬同一插图。
- 右上角只显示本张页码 [2/10]，不显示其他编号。
- 只有第 [10] 张出现引导语；其余各张不出现营销、商品或价格信息。

### 按图文类型补充

| 类型 | 条目 |
|---|---|
| 知识图解 | 分栏标题与表格行基线对齐，表格不合并漏行，优先保证手机放大后的可读性 |
| 图鉴/网格 | 共 [20] 个条目，每个主体完整不裁切，名称紧贴对应主体下方，不重复、不遗漏 |
| 步骤教程 | 步骤编号连续，每一步只新增本步的变化，箭头方向与顺序一致 |
| 对比 | 左右两侧构图对称、同一角色外观一致，只改变需要对比的部分 |
| 流程/关系图 | 只画「节点关系」中列出的连线，装饰曲线不能看起来像关系线 |
| 数据图 | 图形数量与数值按节点绘制，数值逐字标注；不画没有给出的数据 |
| 漫画/绘本 | 角色外观按「角色设定」保持一致；旁白框无尾巴，对话气泡指向说话人 |
| 无字插画 | 画面不出现任何文字、字母、数字或类似文字的纹样 |
| 练习纸 | 这是未作答的练习纸：横线、选择框、连线和涂色区全部空白，不替用户完成 |
| 记录表/信纸 | 所有填写格与横线保持空白，不预填示例内容 |
| PPT | 16:9 横版，四周留安全边距；每页一个观点，文字远看可读 |
| IP/世界观 | 角色与生物为原创形象，不复刻影视、漫画、动画或游戏改编的外观 |
| 人物 | 手部、肢体数量正确，手与物件接触自然，不融合 |
| 地图/路线 | 路线连续不断开，站点编号与侧栏一致；非比例示意图不暗示真实距离 |

## 回避（短词）

挑 8—15 个，最后补本风格最容易出现的问题。

| 类别 | 短词 |
|---|---|
| 文字 | 繁体字、乱码、错别字、伪文字、未列出的文字、文字挤压或裁切、难读的小字 |
| 版面 | 文字遮挡主体、标签重叠、引线交叉、错连引线、无意义箭头、表格漏行、网格缺格 |
| 风格 | 照片质感、3D 渲染、霓虹发光、厚重投影、风格漂移、混入其他画法 |
| 内容 | 虚构数据、旧主题残留、重复节点、额外标题、营销文案 |
| 版权 | 现成版权角色形象、影视/动漫截图、品牌 Logo、水印、签名、App 界面截图 |
| 人物 | 多余肢体、手指错误、手与物件融合、悬空接触 |

## 负向提示词（英文，逗号分隔）

| 类别 | 词 |
|---|---|
| 文字 | blurry text, garbled characters, illegible text, traditional chinese, tiny unreadable type, extra words, invented labels, pseudo text, misspelled words |
| 版面 | overlapping labels, text obscuring illustrations, messy layout, broken layout, distorted tables, cropped text, missing cells, misaligned grid |
| 标识 | watermark, signature, logo, app interface screenshot, ui buttons, screenshot controls |
| 版权 | copyrighted character likeness, anime screenshot, movie still |
| 风格（按需） | photorealism, 3d render, glossy plastic, neon glow, heavy drop shadow, gradients, inconsistent art style, dark text background |
| 人物 | extra fingers, extra limbs, fused hands, deformed face |
| 画质 | low resolution, jpeg artifacts, noisy, oversaturated |

> **正负向不能冲突**：要 3D 黏土，就不要把 `3d render` 写进负向；要水彩，就不要写 `watercolor`；要照片抠图，就不要写 `photorealism`。从「风格（按需）」里只挑与本次画法相反的词。

## 一个通用组合

```text
blurry text, garbled characters, illegible text, traditional chinese, tiny unreadable type, extra words, invented labels, overlapping labels, text obscuring illustrations, broken layout, watermark, signature, logo, app interface screenshot, copyrighted character likeness, inconsistent art style, extra fingers, low resolution
```
