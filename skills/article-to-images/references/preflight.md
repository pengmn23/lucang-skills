# 前置提问

读完内容、判断好图文类型和单张/系列之后，先问清偏好，再写提示词。

| | 单张 | 系列 |
|---|---|---|
| 题目 | 风格、密度 | 风格、密度、内容取舍 2 题 |
| 已答过的 | 不再问 | 不再问 |
| 用户说「你来定」 | 代选并说明 | 代选并说明 |

**等用户回答再写提示词。** 推荐项、预选项、沉默都不算回答。只回答了一部分时，只补问没答的。同一套图后续修改时，保留已选的答案，只问受影响的部分。

## 1. 风格三选一

给 3 个**画法上明显不同**的方向，不能只是换颜色。每个选项写：

- 短名称；
- 1—2 句说明：画法/媒介、背景与主色、标题和正文的字体气质；
- 为什么适合这篇内容。

推荐一个，放在第一位并标「推荐」。此时只给简短描述，不给完整 JSON。

风格从哪里来：

| 用户输入 | 怎么出 3 个选项 |
|---|---|
| 没有参考 | 按内容和图文类型新拟，或从 [风格速配](../library/README.md#风格速配) 挑 3 套合适的，可以改写 |
| 给了一张参考图 | 先实际看图，判断它主要参考**画法**还是**版式**。三个选项都保留其核心特征：①忠实提炼；②保留画法、更清爽；③保留画法、换一种图形表达。说明每个选项保留什么、调整什么 |
| 指定了某种风格（如「国风」「黑板粉笔」） | 已定的部分直接带入，只在剩余空间里给 3 个变体；用户说「就这样」则直接记为已选 |
| 文字要求和参考图冲突 | 指出冲突，只就冲突处补问 |

看图时不能凭印象下判断；没看到的特征不要写进选项。不要复制参考图里的旧标题、旧主体和事实。

## 2. 文字密度

固定给出四档，按图文类型推荐一档并说明取舍：

| 选项 | 每张上屏字数 | 说明给用户的取舍 |
|---|---|---|
| 纯画面 | 0 | 只靠画面表达；适合绘本内页、无字漫画、插画素材 |
| 低 | 约 50 | 画面空间大、一眼看懂；信息要精选，覆盖全文可能需要更多张 |
| 中 | 约 150 | 图文兼顾，适合手机知识卡、流程、对比 |
| 高 | 约 300 | 信息完整，适合速查表、资料页；需要放大阅读，装饰要少 |

纯画面只在类型适合时列出（绘本、漫画、插画、海报），知识卡等类型可以省略这一档。数字是目标，不是硬配额；封面可以比所选档位少字。

## 3. 内容取舍 2 题（仅系列）

读完内容再出题，让不同答案真的会改变分图或内容。每题 2—3 个选项，推荐项在前。两题之间、与风格和密度之间不重复。

可以从这些方向里挑最相关的两个，并写成本文的具体语境：

- **读者基础**：第一次接触 / 知道名词但不熟 / 已有基础想系统整理
- **内容重点**：原理 / 操作步骤 / 案例（只列原文里有的）
- **覆盖方式**：全篇脉络 / 少数重点深讲 / 一个案例贯穿
- **组织方式**：顺序讲解 / 并列速查 / 对照辨析
- **结尾处理**：总结页 / 行动清单 / 引导语（用户已指定商品或引导时不再问）
- **事实边界**：只讲原文主线 / 加入原文中的扩展内容

不要用张数、比例充当内容题；张数和比例缺失时按默认处理并说明。不要出「你想怎么做」这类空泛问题。

## 4. 怎么问

- 环境有选择题工具时，一次提交全部未决题，每题能独立看懂。
- 没有选择题工具时，用文字列出题目和 A/B/C 选项，让用户按「1A 2B」回答，也可以自由补充。
- 问完就停下等回答。等待期间可以继续读原文、核对资料，但不写依赖答案的提示词。

## 5. 收到回答后

用一两句话复述：类型、单张/系列（几张）、风格、密度、内容取舍。然后开始写。

系列有文件工具时，把问题、选项、推荐理由和实际答案存为 `00_需求选择.md`；注明每个答案来自用户选择、用户已给还是用户委托代选。这份记录不放进每张 JSON。

## 示例

### 单张：用户要一张「番茄工作法」小红书干货卡

1. 风格：A 白底手绘干货（黑线三原色、马克笔大字，推荐，适合方法类干货）；B 马克笔课堂（彩色圆角卡、荧光高亮，更活泼）；C 极简大字（纯色底、巨大数字 25，更像海报）。
2. 密度：A 约 150 字（四个步骤各一句解释，推荐）；B 约 50 字（只留步骤名）；C 约 300 字（加入常见问题，需放大）。

### 系列：用户要把一篇 3000 字的「阳台种薄荷」做成 6 张图

1. 风格：A 自然观察手帐（透明水彩彩铅，推荐）；B 黏土童趣（适合亲子）；C 照片抠图知识卡（真实感强）。
2. 密度：A 约 150 字（推荐）；B 约 50 字；C 约 300 字。
3. 内容重点：A 从扦插到收获的操作步骤（推荐，原文主体）；B 常见问题与处理；C 两者各半。
4. 读者：A 第一次养植物（推荐）；B 养过其他植物、想快速上手。
