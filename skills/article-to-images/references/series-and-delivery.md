# 系列与交付

做一套图（含 PPT）或要继续出图时读这份文件。单张只需看「交付」和「首图参考出图」中的单张部分。

## 分图规划

前置提问完成后，先写规划给用户看，再写逐张提示词。通常可以在同一轮完成；用户要求先审规划时停下。

规划逐张写：

| 字段 | 写法 |
|---|---|
| 序号 / 文件名 | 1 / `001.json` |
| 页标题 | 本张的主标题（会上屏） |
| 原文定位 | 对应原文的哪一节、哪几段 |
| 本张任务 | 这一张要让读者明白什么 |
| 版式 | 选用的版式编号与一句描述，如「L16 纵向五步」 |
| 节点规划 | 每个根节点一句话：`01 主插画：…`、`02 步骤1：…` |
| 预计上屏字数 | 按所选密度估算；封面等例外写原因 |

规划末尾写：

- **张数依据**：用户指定，或建议值与理由。
- **覆盖与取舍**：哪些内容合并、压缩、省略。张数多而内容少时，说明哪些张是原文例子的展开，不为凑数编内容。
- **风格微调**：默认「无」。有的话写「第 N 张｜字段｜原值→新值｜原因」。

有文件工具时，规划存为 `00_分图规划.json`（或 `.md`），格式示例见 [examples/series](../examples/series/00_分图规划.json)。

## 风格母版

母版是全套共用的风格部分，存为 `01_风格母版.json`。它就是一份完整模板，只是本张内容字段（核心主题、布局、标题文字、节点）先留成说明。

母版里锁定、每张逐字照抄的字段：

- `信息图全局配置`：画布比例、语言规范、阅读场景、视觉美学、系列风格锚点
- `视觉风格系统` 全部
- `标题艺术系统`：除 `标题文字内容` 外全部
- `内容标签系统` 全部
- `配色方案`、`光影效果` 全部
- `角色设定`（如有）
- `渲染参数与负向` 全部
- `硬性指令约束` 中的通用条目

每张可以变：核心主题、系列编号、布局架构、视觉逻辑、页码标注、标题文字内容、节点、节点关系、本张专属约束。

**不要每张换同义词重写风格**。同一个意思换种说法，模型就可能画出不同的东西。封面也用同一套画法和字体，只是标题和主视觉占比更大。

## 交付目录

有文件工具时，默认在原文旁边新建 `<文章名>_图片方案/`，用户指定位置优先：

```text
<文章名>_图片方案/
├── 00_需求选择.md
├── 00_分图规划.json
├── 01_风格母版.json
├── 02_逐张提示词/
│   ├── 001.json
│   └── ...
├── 03_提示词合集.md
└── 04_出图记录.md        （只在实际出图时创建）
```

- `03_提示词合集.md`：开头放规划表和固定风格说明，然后按序号放每张**完整** JSON 代码块，方便通读和复制。
- 没有文件工具时：在对话里按「需求选择 → 分图规划 → 风格母版 → 逐张完整 JSON → 取舍说明」的顺序完整给出，并说明尚未保存成文件。输出太长被截断时，分几条消息继续，直到 N 张全部给完。

修改时：只改某张就同步规划、该张 JSON 和合集；改母版要同步全部 N 张；增减张数要重新编号。保留旧版，不覆盖原文。

## 首图参考出图

### 单张

用完整 JSON 生成。检查后若有问题，写清楚改什么、保留什么，再针对性重试。

### 系列

1. **先出第 1 张**。检查画风、背景、配色、标题与正文样式、文字是否正确、节点数量与关系、手机可读性。不合格先修好。用户指定了合格首图或参考图时直接沿用。
2. **后面每张都附上同一张首图**，通过工具真正的参考图输入传入，不只在文字里写「参考附件」。在该张 JSON 之外加一段说明：

   > 附件图片仅作为本系列的美术与文字样式参考。请保持与附件相同的美术风格、媒介、背景、配色、标题样式与字体、正文与标签样式；当前图片的主题、文字、视觉元素和布局按本条 JSON 执行。不要复制参考图中的旧标题、旧文字和无关主体，不要把参考图拼进画面，也不要把这段说明画进图里。

3. **始终以首图为准**，不要每张只参考上一张，否则风格会一点点漂移。中途更换首图，要记录哪些张受影响。
4. 工具不支持参考图：告诉用户限制，由用户决定换工具或接受纯文字生成。
5. 每张生成后就保存，记录：序号、使用的 JSON 版本、输出路径、附带的参考图、尺寸、检查结果、返工情况。
6. 结束时分开报告：计划 N 张 / 提示词完成 / 实际生成 / 检查通过 / 未完成。拼图不算 N 张独立图片。

### 逐张检查要看什么

- 文字：逐字核对，尤其是专名、数字、标点；有没有多出来的字、伪文字
- 数量：网格格数、步骤数、条目数是否与节点一致
- 关系：箭头和引线是否连对，装饰线是否被误读成关系
- 风格：与首图是否同一套画法、配色、字体
- 可读：手机屏幕上标题和正文能否看清

`04_出图记录.md` 用来记这些结果。没有实际生成时不创建，也不要把「提示词写好了」写成「已出图」。
