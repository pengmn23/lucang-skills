
# 手绘笔记风配图风格规定

> 用这套风格画教学类配图：封面、概念图解、流程图、对比图、总结图。截图、实验对比图这类不用它。
> 出图有两条路，风格一致：
> - **代码画图**：本 skill 的 `scripts/render.py`，写一份 JSON 出 PNG。文字一个不错，适合字多、要反复改的图。
> - **生图模型**：用第一、九节的关键词写提示词，质感更像手绘，可能出错字。
> 改了这份规定，`scripts/sketchnote.html` 里的颜色常量也要跟着改。

示例：`assets/示例/示例_竖版流程图.png`（3:4）、`assets/示例/示例_六个字段速查.png`（16:9）。

## 一、风格一句话

**手绘笔记风的教学图解**：奶油色纸底，黑色马克笔手绘线条，蓝、橙、绿三种颜色各代表一类角色，荧光笔高亮重点，旁边有手写批注和小涂鸦。像一位认真的老师，在笔记本上把一件事画清楚。

关键词（写提示词时用）：手绘笔记风（sketchnote）、手账信息图、马克笔线稿、扁平填色、荧光笔高亮、手写批注。

## 二、画布和版面

| 项目 | 规定 |
|---|---|
| 比例 | **默认 16:9 横版**。代码画图的画布是 1600×900，出图 3200×1800；用生图模型就选 16:9、2K。要发小红书等竖版平台的图另做 3:4 |
| 分辨率 | 定稿用 2K、中画质以上；字多的图用高画质 |
| 四周留白 | 约 3% 的纸边，不贴边 |
| 区域（16:9） | 上：标题区，约占 18%，标题一行；左：主图区，约占宽度的 68%；右：侧栏，约占 30%，从上到下放图例、关键关系、边界说明或便利贴 |
| 区域（3:4） | 上：标题区约 20%；中：主图区约 55%；下：总结区约 25% |
| 阅读顺序 | 从左到右、从上到下；主流程用箭头串起来，回路用一条大弧线绕回去 |
| 密度 | 内容饱满但不挤：节点 4–10 个，每个节点的说明不超过两行 |

## 三、配色

色号只是目标，出图后要看实际颜色。

| 用途 | 颜色 | 参考色号 |
|---|---|---|
| 纸底 | 暖奶油白，带极淡的纸纹 | `#FAF6EC` |
| 线条、正文字 | 近黑炭灰，不用纯黑 | `#2B2B2B` |
| 蓝：输入类节点 | 天蓝 | `#5BA3E6`，浅底 `#DDEBFA` |
| 橙：生产类节点 | 暖橙 | `#F5A04A`，浅底 `#FDE7CF` |
| 绿：反馈类节点 | 草绿 | `#6CC27A`，浅底 `#DDF2DA` |
| 高亮 | 荧光黄、樱花粉、浅薄荷绿（像荧光笔涂过） | `#FFE47A`、`#F8C8D3`、`#CDEFC4` |
| 点缀 | 图钉红、警示红（只用在图钉、警示牌） | `#E5533D` |

- 画面主色只有蓝、橙、绿三种，加上黑线和奶油底。不再加紫色、粉紫渐变这类「AI 科技感」配色。
- 节点用饱满的扁平色块；说明文字放在同色系的浅底圆角块里。

## 四、线条

- 黑色马克笔手绘线：粗细略有起伏，线头圆润，转角带一点手抖，不是尺规画的直线。
- 节点外框是粗线（约为正文笔画的 2 倍）；连接箭头是中等粗细；批注里的小箭头、圈注是细线。
- 箭头用实心三角箭头头；主流程箭头略带弧度，回路用一条长弧线。
- 虚线圆角框：用于图例、总结版块。

## 五、形状的意思（一套图里统一）

| 形状 | 颜色 | 代表 | 例子 |
|---|---|---|---|
| 圆形 | 蓝 | 输入：资料、想法、灵感、来源 | 文章、资料、读者的需求 |
| 圆角方块 | 橙 | 生产：做出来的东西、动作 | 提示词、出图、修改 |
| 六边形 | 绿 | 反馈：检查、复盘、沉淀 | 验收、作图清单、模板 |
| 箭头 | 黑 | 先后和依赖关系 | — |

同一张图里，同一类东西用同一种形状和颜色。每张图都放一个小图例，说明形状和颜色的意思。

## 六、文字

| 层级 | 写法 | 字数 |
|---|---|---|
| 主标题 | 粗黑手写马克笔字；16:9 写一行，3:4 写两行；最关键的几个字用荧光黄高亮 | 16:9 一行 20 字以内；3:4 每行 12 字以内 |
| 英文副标题（可选） | 细线手写大写字母，压在樱花粉高亮条上 | 4 个英文单词以内 |
| 节点标签 | 白色粗圆体，写在色块里，图标下方 | 2–4 字 |
| 节点说明 | 深灰手写字，放在同色浅底的圆角块里 | 两行以内，每行 10 字左右 |
| 批注 | 深灰手写字，斜放在空白处，带小箭头或感叹号 | 每条 15 字以内，一张图 2–4 条 |
| 版块标题 | 粗手写字，配一个小图标，下面压一条高亮 | 4–6 字 |
| 署名（可选） | 手写签名，放左下角；左下角被占了就放侧栏底部 | 你自己的名字 |

- 所有中文为简体中文。图里出现的每一个字，都要在提示词里写出来（文字白名单）；不让模型自己补字。
- 英文只用在副标题和右下角的手写小字里，正文不用英文。
- 字多的图，先在对话里把文案定好，再出图。

## 七、图标和小涂鸦

- **节点图标**：白色、扁平、线条简单的图标，放在色块中间偏上（灯泡、文档、靶心、笔和纸、图片、纸飞机、柱状图、叠放的方块……）。
- **装饰小涂鸦**（一张图挑 3–5 个，不压在文字上）：发光的灯泡、三条短线的「闪光」、感叹号、小星星、红色图钉、便利贴、喇叭、回形针或链条、小草、木头路牌。
- 便利贴、路牌这类元素可以带一点轻微的倾斜，增加手写感。

## 八、固定版块（按需要选用）

| 版块 | 位置 | 写法 |
|---|---|---|
| 节点图例 | 16:9 放侧栏上部，3:4 放主图区右上；虚线圆角框，配红色图钉 | 列出每种形状、颜色的意思 |
| 关键关系 | 16:9 放侧栏中部，3:4 放总结区左侧；喇叭图标 | 2–4 条，用蓝、橙、绿、红编号圆圈 |
| 关键回路 | 总结区或侧栏，虚线框 + 链条图标（16:9 侧栏放不下时可以省掉） | 一行流程，用荧光黄高亮条压住，下面一句话说明 |
| 边界说明 | 16:9 放右上角或侧栏底部，3:4 放总结区右侧；木头路牌 + 警示三角 | 一句话说明这张图的适用范围或不灵的情况 |
| 署名（可选） | 左下角 | 手写签名 |

## 九、不要这样画

- 不要 3D、立体浮雕、渐变、发光、霓虹、玻璃质感、照片质感。
- 不要明显的投影；色块是扁平的。
- 不要整齐的电脑矢量风、尺规直线、科技感 UI 界面。
- 不要多余的英文、乱码、编号、水印；不要把字段名、引号画进图里。
- 不要堆满装饰：装饰只是点缀，信息和关系才是主角。
- 不要用真人肖像、品牌 logo。

## 十、出图后检查

出图后看这几项：

- [ ] 主色只有蓝、橙、绿，形状和颜色的意思和图例一致
- [ ] 线条有手绘感，没有渐变和 3D
- [ ] 每一个字都和提示词里写的一致，没有多出来的字
- [ ] 箭头方向对，回路从哪里绕回哪里是对的
- [ ] 手机上看，节点说明和批注都看得清
- [ ] 有署名的话，在左下角，没有被裁掉
