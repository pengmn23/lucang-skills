# 在浏览器里改图

1. **打开**：双击 `scripts/打开配图工具.command`，或让 Agent 跑 `render.py --edit <JSON>`。
2. **开始一张图**：
   - 改已有的图：点「打开」，选 `specs/` 里的 JSON；也可以直接把 JSON 文件拖进页面。
   - 新做一张：点「＋ 新建…」选一个模板（流程闭环、上下两组对比、四步循环、空白横版、竖版 3:4）。
3. **改**：
   - **拖动**图上的任何东西：节点、说明块、连线标签、批注、版块、图例、标题、署名。会自动对齐到 5 像素，按住 Shift 可以自由移动。拖动分组框时，框里的节点跟着走。
   - **双击**节点、批注、标题、清单：直接改文字，用「/」分行。
   - **点选**一个元素，右边只显示它的字段，改了马上生效；方向键微调，Shift + 方向键一次 10 像素。
   - 顶部按钮加东西：「＋输入 / ＋生产 / ＋反馈」加节点，「＋连线」再依次点起点、终点两个节点，「＋批注」「＋便利贴」「＋清单」。
   - 右边点一个**图标**，就换掉选中节点的图标；点一个**小涂鸦**，加到画面中间。
   - 改错了：⌘Z 撤销，⇧⌘Z 重做。Delete 删除，⌘D 复制。
4. **看提醒**：右边「排版提醒」列出重叠和超出画布的地方，点一条就选中对应的元素，拖开就好。
5. **保存**：⌘S 直接存回打开的那个文件；新建的图第一次保存时选位置，存进项目的 `specs/`，命名 `<章节号>_<图号>_<内容>.json`。没保存就关页面会提醒；万一关了，下次打开会恢复草稿。
6. **出图**：「导出 PNG」存到「下载」文件夹（3200×1800），适合先看效果。正式出图让 Agent 跑 `render.py`，会按 JSON 里的 `output` 直接存进章节的图片文件夹。

整份 JSON 平时收着，点「显示 JSON」才出现；「复制」可以把整份 JSON 发给 Agent。
